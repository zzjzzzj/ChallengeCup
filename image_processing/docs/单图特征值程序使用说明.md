# 单图入选特征值提取程序

程序文件为 `feature_infer.py`。它会复用特征工程阶段完全相同的图片预处理和特征计算方法：图片先转为灰度图并缩放到 128×128，再计算全部 68 个视觉特征，最后只输出 ANOVA 特征工程筛选出的 30 个特征值。

## 1. 只查看筛选后的特征值

在项目根目录运行：

```powershell
python .\scene_recognition\feature_infer.py `
  --image "待处理图片.png" `
  --features-only
```

输出为 JSON，其中 `selected_feature_values` 保存“特征名 → 对应值”。

## 2. 将结果保存为 JSON 文件

```powershell
python .\scene_recognition\feature_infer.py `
  --image "待处理图片.png" `
  --features-only `
  --output ".\output\图片特征值.json"
```

## 3. 同时输出场景分类结果

不添加 `--features-only` 即可。程序默认加载项目已有的 SVM 模型和元数据，无需再手动填写模型路径：

```powershell
python .\scene_recognition\feature_infer.py --image "待处理图片.png"
```

此时输出除 30 个特征值外，还包括预测场景、置信度和四类场景概率。

## 输出示例

```json
{
  "image": "图片的绝对路径",
  "selected_feature_count": 30,
  "selected_features": ["int_std", "int_p50", "..."],
  "selected_feature_values": {
    "int_std": 0.123456789,
    "int_p50": 0.501960814,
    "tex_edge_density": 0.145019531
  }
}
```

实际结果会完整输出全部 30 个入选特征。特征值保留 9 位小数，便于后续保存、比较或输入其他程序。
