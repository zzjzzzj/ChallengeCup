# 遥感场景特征分析台使用说明

可视化分析台用于展示单幅图片的特征工程结果。它与命令行程序共用同一套图片预处理、68 项候选特征计算、ANOVA 筛选结果和 SVM 分类模型。

## 首次使用

在项目根目录安装依赖：

```powershell
python -m pip install -r .\scene_module\requirements.txt
```

## 启动页面

推荐运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scene_module\run_feature_dashboard.ps1
```

也可以直接运行：

```powershell
python .\scene_module\feature_web_app.py
```

程序会自动打开浏览器并访问：

```text
http://127.0.0.1:8501
```

如不希望自动打开浏览器：

```powershell
python .\scene_module\feature_web_app.py --no-browser
```

## 页面功能

1. 上传或拖入 PNG、JPG、BMP、TIFF 图片，单文件不超过 16 MB。
2. 显示 air、sea、urban、forest 四类场景概率与最高置信度结果。
3. 显示特征相对训练集均值的标准分数谱，便于判断该图像在哪些特征上比较特殊。
4. 完整列出 30 个入选特征的中文名称、程序字段、原始值、标准分数和特征重要度。
5. 按灰度分布、纹理结构、频域信息筛选特征。
6. 将当前分析结果导出为 JSON 文件。

## 数值说明

- “原始值”是图片经过灰度化并缩放为 128×128 后，根据现有特征工程公式直接计算出的值。
- “标准分数”使用训练集均值与标准差计算：0 表示接近训练集平均水平，正值表示高于平均水平，负值表示低于平均水平。
- 标准分数用于辅助解释，不会替代模型内部的 `StandardScaler + ANOVA SelectKBest` 处理。
- 页面只监听本机 `127.0.0.1`，上传的图片不会发送到外部服务。

## 停止程序

回到运行程序的 PowerShell 窗口，按 `Ctrl+C` 即可停止。
