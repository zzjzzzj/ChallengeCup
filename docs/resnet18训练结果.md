# 多模态遥感图像识别项目：方法、训练与成果总结

## 1. 项目任务

项目数据由IR红外图像和SAR图像组成，包含四类场景和四类目标。

场景类别：

- `air`：空中
- `sea`：海面
- `urban`：城市
- `forest`：森林

目标类别：

- `soldier`：士兵
- `small_aircraft`：小型飞机
- `warship`：军舰
- `tank`：坦克

当前项目包含三部分：

1. 使用手工特征和传统分类器识别四类场景。
2. 使用ResNet18从整张图中直接判断四类目标是否存在，这是当前目标识别主线。
3. 使用真实框裁剪分类和YOLOv8目标检测作为对照实验。

### 2.2 训练集、验证集和测试集划分

数据不是完全随机划分，而是在每个“传感器×场景”子组内，按照文件名中的序列编号排序后划分：

```text
前70%   → 训练集
中间15% → 验证集
后15%   → 测试集
```

实际划分结果：

| 数据集 | 总数  | IR  | SAR |
| --- | ---:| ---:| ---:|
| 训练集 | 525 | 378 | 147 |
| 验证集 | 114 | 82  | 32  |
| 测试集 | 111 | 80  | 31  |
| 总计  | 750 | 540 | 210 |

按场景统计：

| 数据集 | air | forest | sea | urban |
| --- | ---:| ------:| ---:| -----:|
| 训练集 | 122 | 142    | 119 | 142   |
| 验证集 | 26  | 31     | 26  | 31    |
| 测试集 | 27  | 30     | 24  | 30    |

这种顺序划分可以减少相邻帧随机进入训练集和测试集造成的指标虚高，也使测试集更接近“用前段序列训练、识别后段序列”的实际情况。

### 2.3 划分注意事项

当前IR与SAR在各自的“传感器×场景”子组内独立划分。175组同场景、同编号的候选IR/SAR对中，有56组被分到了不同集合。

目前只能确认这些图像文件名对应，不能确认它们是严格配准的同一次拍摄。如果后续确认同编号IR/SAR属于同一目标或同一时刻，应改为按照`scene + sequence_index`整体分组划分，避免跨模态信息泄漏。

## 3. 手工特征工程

### 3.1 特征工程的用途

手工特征用于识别`air、sea、urban、forest`四类场景，为轻量、可解释的场景识别提供基线。

手工特征和ResNet18目标识别是两条不同实验路线：

```text
手工30维特征 → 场景分类
完整图像 → ResNet18 → 目标存在识别
```

当前ResNet18主模型没有拼接这30维手工特征。

### 3.2 特征提取方法

每张图片先转换为灰度图，并缩放至128×128，然后提取68个视觉特征。

| 特征组  | 数量  | 主要内容                             |
| ---- | ---:| -------------------------------- |
| 灰度分布 | 21  | 均值、标准差、分位数、动态范围、熵、偏度、峰度、明暗像素比例   |
| 纹理结构 | 41  | Sobel梯度、边缘密度、拉普拉斯、局部标准差、LBP、GLCM |
| 频域特征 | 6   | 低中高频能量、频谱熵、加权频率半径                |
| 合计   | 68  | 不包含传感器类型字段                       |

### 3.3 30维特征筛选

特征筛选采用ANOVA单变量检验`SelectKBest(f_classif)`。分别尝试保留5、10、15、20、30、40、50和60个特征，根据验证集Macro-F1确定保留30个特征。

最终30个特征为：

#### 灰度分布特征：8个

1. `int_std`：灰度标准差
2. `int_p50`：灰度50%分位数
3. `int_p75`：灰度75%分位数
4. `int_p90`：灰度90%分位数
5. `int_p95`：灰度95%分位数
6. `int_p99`：灰度99%分位数
7. `int_dynamic_range`：1%到99%灰度动态范围
8. `int_entropy`：灰度信息熵

#### 梯度与局部纹理特征：4个

9. `tex_grad_p90`：梯度强度90%分位数
10. `tex_edge_density`：边缘密度
11. `tex_local_std_mean`：局部标准差均值
12. `tex_lbp_entropy`：LBP纹理熵

#### LBP直方图特征：15个

13. `tex_lbp_00`
14. `tex_lbp_01`
15. `tex_lbp_02`
16. `tex_lbp_03`
17. `tex_lbp_04`
18. `tex_lbp_05`
19. `tex_lbp_06`
20. `tex_lbp_07`
21. `tex_lbp_09`
22. `tex_lbp_10`
23. `tex_lbp_11`
24. `tex_lbp_12`
25. `tex_lbp_13`
26. `tex_lbp_14`
27. `tex_lbp_15`

#### GLCM空间灰度关系特征：2个

28. `tex_glcm_d2_homogeneity`：距离2的灰度共生矩阵同质性
29. `tex_glcm_d4_homogeneity`：距离4的灰度共生矩阵同质性

#### 频域特征：1个

30. `freq_spectral_entropy`：频谱熵

### 3.4 场景分类模型

30维特征经过标准化后，输入RBF-SVM分类器：

```text
30维特征
   ↓
StandardScaler标准化
   ↓
RBF-SVM（C=3，class_weight=balanced）
   ↓
air / sea / urban / forest
```

特征数量只使用训练集和验证集选择。选定30维后，使用训练集和验证集重新拟合模型，测试集只用于最终评估。

会议中提到过Extra Trees分类器整合，但当前仓库中具有完整可复现指标的是上述`StandardScaler + ANOVA SelectKBest + RBF-SVM`流程，因此本报告不把未复核的Extra Trees结果作为最终结果。

### 3.5 场景特征工程结果

| 指标             | 结果     |
| -------------- | ------:|
| 测试Accuracy     | 92.79% |
| 测试Macro-F1     | 92.25% |
| 测试Macro-Recall | 92.08% |

分类别召回率：

| 场景     | Recall  |
| ------ | -------:|
| air    | 100.00% |
| sea    | 75.00%  |
| urban  | 96.67%  |
| forest | 96.67%  |

实验表明纹理特征最有效，LBP、梯度、局部标准差和GLCM同质性对场景区分贡献较大。最困难的是IR海面场景。

## 4. ResNet18整图目标识别

### 4.1 任务定义

一张遥感图可能同时包含多个目标，因此不能使用普通四选一分类。模型需要分别判断四类目标是否存在。

例如，一张图片同时包含士兵和坦克：

```text
[soldier, small_aircraft, warship, tank]
[   1,           0,          0,     1]
```

测试集111张图片中，有60张同时包含`soldier`和`tank`，证明该任务必须使用多标签分类。

### 4.2 模型流程

```text
完整遥感图
    ↓
黑色补边为正方形
    ↓
缩放到224×224
    ↓
ImageNet mean/std归一化
    ↓
ImageNet预训练ResNet18
    ↓
4个独立Logit
    ↓
Sigmoid + 每类验证集阈值
    ↓
输出图中存在的目标类别
```

YOLO标注在训练阶段只用于生成每张图的四维“类别是否存在”标签。整图ResNet18不使用标注框位置。

### 4.3 训练配置

| 项目         | 设置                |
| ---------- | ----------------- |
| 模型         | ResNet18          |
| 预训练        | ImageNet          |
| 输入尺寸       | 224×224           |
| 训练轮数       | 12                |
| Batch Size | 32                |
| 优化器        | AdamW             |
| 初始学习率      | 0.0003            |
| 权重衰减       | 0.0001            |
| 学习率调度      | CosineAnnealingLR |
| 损失函数       | BCEWithLogitsLoss |
| 类别不平衡处理    | 按训练集计算正样本权重       |
| 数据增强       | `none`，无增强基准组     |
| 随机种子       | 42                |
| 模型选择       | 验证集Macro-F1最高     |
| 输出阈值       | 在验证集上按类别分别确定      |

最终阈值：

| 目标             | 阈值   |
| -------------- | ----:|
| soldier        | 0.50 |
| small_aircraft | 0.60 |
| warship        | 0.50 |
| tank           | 0.50 |

### 4.4 整图ResNet18结果

| 指标              | 结果     |
| --------------- | ------:|
| Exact Match     | 90.99% |
| Micro-F1        | 94.77% |
| Macro-F1        | 92.37% |
| Macro-Precision | 93.45% |
| Macro-Recall    | 92.92% |
| 标签平均AP          | 99.14% |

Exact Match要求一张图片的四个目标存在判断全部正确。111张测试图片中，101张完全正确，10张存在错误。

分类别结果：

| 目标             | Precision | Recall  | F1     |
| -------------- | ---------:| -------:| ------:|
| soldier        | 98.33%    | 98.33%  | 98.33% |
| small_aircraft | 77.14%    | 100.00% | 87.10% |
| warship        | 100.00%   | 75.00%  | 85.71% |
| tank           | 98.33%    | 98.33%  | 98.33% |

分模态结果：

| 模态  | 测试图片数 | Exact Match |
| --- | -----:| -----------:|
| IR  | 80    | 87.50%      |
| SAR | 31    | 100.00%     |

### 4.5 错误分析

- 10张错误图片全部来自IR模态。
- 主要问题是6张IR海面图漏识别`warship`。
- `small_aircraft`出现8次误报。
- 验证集达到100%，测试集降至90.99%，说明后段测试序列与训练数据存在分布差异。
- `small_aircraft`与air场景、`warship`与sea场景高度绑定，模型可能利用场景背景作为识别捷径。

## 5. ResNet18真实框裁剪分类对照

### 5.1 方法

读取YOLO真实标注框，将每个目标从原图中裁剪出来，再使用ResNet18进行单标签四分类。

```text
原图 + YOLO真实框
        ↓
    单目标裁剪图
        ↓
     ResNet18
        ↓
soldier / small_aircraft / warship / tank
```

数据必须先按原图划分，再裁剪目标。同一原图产生的所有裁剪目标继承原图的数据集，不能随机分散到训练集和测试集。

### 5.2 裁剪数据量

| 数据集 | 裁剪目标数 |
| --- | -----:|
| 训练集 | 2025  |
| 验证集 | 459   |
| 测试集 | 473   |
| 总计  | 2957  |

### 5.3 结果

| 指标       | 结果     |
| -------- | ------:|
| Accuracy | 99.79% |
| Macro-F1 | 99.78% |

473个测试裁剪目标中只有1个错误：一个11×11像素的IR森林场景坦克被识别为士兵。

该结果只表示“已知正确目标位置后能否分对类别”，不能代表完整原图目标检测性能。

## 6. YOLOv8完整目标检测对照

YOLOv8直接输入完整图片，同时预测目标类别和边界框位置。

| 指标           | 结果     |
| ------------ | ------:|
| 测试图片数        | 111    |
| 测试目标框        | 473    |
| Precision    | 84.66% |
| Recall       | 78.79% |

## 9. 当前限制与下一步

> 本节在 2026-07-26 的诊断后重写。完整证据见
> [`诊断报告-场景捷径与模型选择缺陷.md`](诊断报告-场景捷径与模型选择缺陷.md)。
> 此前版本把其中多条列为“风险/可能”，现已实测确认，措辞相应改为结论。

### 9.1 已确认的限制

- **整图多标签任务已退化为场景分类。** 四维存在标签是场景的确定性函数：
  air 恒为 `[0,1,0,0]`、sea 恒为 `[0,0,1,0]`、urban 与 forest 恒为 `[1,0,0,1]`，
  750 张图零例外，全数据集只出现 3 种存在向量（理论有 16 种）。
  完美场景分类器即可取得 100% Exact Match，因此该指标不能作为目标识别能力的证据。
- **场景背景捷径已从“可能”确认为“成立”。** 测试集像素消融：
  抹掉全部真实框内像素后 Exact Match 仅由 99.10% 降至 98.20%；
  反过来只保留目标、抹掉背景则降至 34.23%，低于恒定预测的 54.05%。
  即模型基本不依赖目标像素。
- **裁剪分类 99.79% 的平凡上限为 97.67%。** 完全不看像素，
  仅用「场景 one-hot + 框宽高/面积/长边/长宽比」的深度 ≤4 决策树即可达到 97.67%；
  urban/forest 内 soldier 与 tank 仅凭框宽度单阈值（17.5 px）就能分对 95.11%。
  ResNet18 相对平凡基线的净增益只有 2.12 个百分点。
- **此前公布的 90.99% 来自第 1 轮欠训练权重。** 验证集 Macro-F1 第 1 轮即达 1.0，
  而模型选择使用严格大于，导致 `best.pt` 被锁定在第 1 轮。
  修正选择规则后选中第 8 轮，测试 Exact Match 98.20%、Macro-F1 98.30%
  （产物 `runs/resnet18_whole_image_fixed_selection_none/`）；
  3 个随机种子的测试 Macro-F1 为 98.15%±0.61。
- **验证集已失去区分能力。** 114 张、第 1 轮即饱和；
  种子噪声实测标准差为 0.61 个百分点，测试集 111 张、1 张图 = 0.90 个百分点。
  任何小于约 1.2 个百分点的组间差异都不能声称显著。
- 整图ResNet18只判断有哪些目标，不输出目标位置和数量。
- **air 场景只有 IR 图像**，SAR 覆盖 forest/sea/urban 三类，缺 air；
  `small_aircraft` 的 699 个框全部来自 IR，SAR 侧为 0，
  故 SAR 专家在结构上不可能学会该类，双专家对比必须按可学类别分别报告。
- IR/SAR 候选配对尚未确认严格配准：175 组同场景同序号的配对中 56 组落在不同划分。
- **顺序划分的边界间隔实测为 1 帧**（七个 sensor×scene 组全部如此），
  训练集末帧与验证集首帧是相邻近重复帧，仍存在边界泄漏。
- 当前ResNet18结果是无增强基准组，不能直接宣称旋转、翻转、取反或开闭运算有效。

### 9.2 下一步优先级

1. **重新定义整图任务**，使其不能靠场景蒙对。可选：改用 YOLOv8 检测作为主线；
   或改为目标计数；或构造跨场景评测（把 tank 放进 air 背景等）。
2. 用修正后的选择规则、多种子重跑三条基线，替换各文档中的旧数字。
3. 裁剪分类改为报告**相对平凡基线的净增益**，并补一组尺寸归一化实验排除分辨率线索。
4. 划分之间加入缓冲帧后重新生成清单，给出泄漏前后的对照。
5. 确认IR/SAR同编号图像是否属于同一配对；若是，重新进行配对分组划分。
6. 增广消融（`flip、rotate90、invert、open、close`）推迟到第 1～4 项完成后再做，
   且必须多种子、报告均值±标准差；否则结论落在噪声内。
7. 针对IR海面数据训练或微调独立IR专家。
8. 接入持续学习与抗遗忘实验——赛题核心是“时变场景的快速学习”，
   `scene_recognition/detector_module/configs/incremental_protocol.json` 已有协议但尚未跑通，这是当前差距最大的一块。
9. 在昇腾310B上完成ONNX转OM、精度核对和FPS测试。

## 10. 最终结论

项目已经形成“可解释场景特征基线、ResNet18整图识别、真实框裁剪分类、YOLOv8完整检测”的完整实验体系，
工程链路（数据审计、划分、训练、评价、导出、自动测试）是可复现的。

但就**目标识别能力**而言，当前结论必须保守表述：

- 30维手工特征结合RBF-SVM在四场景识别上获得 92.79% 测试准确率；
- ResNet18 整图多标签模型修正选择规则后测试 Macro-F1 为 98.15%±0.61，
  然而该任务的标签与场景一一对应，且像素消融证明模型读的是背景，
  **该数字衡量的是场景识别，不能作为目标识别成果汇报**；
- 真实框裁剪分类 99.79%，但不看像素的平凡基线已达 97.67%，净增益 2.12 个百分点；
- YOLOv8n 完整检测 mAP@0.5 为 81.28%，
  **它是三条线中唯一无法靠场景背景蒙对的指标，应作为目标识别能力的主要依据**。
