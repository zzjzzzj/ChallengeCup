# 运行与部署

## 本地运行

推荐 Python 3.11 或 3.12。根据本机 CUDA/CPU 环境先安装 PyTorch，再安装仓库依赖。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip

# 按 https://pytorch.org/get-started/locally/ 安装 torch 和 torchvision
pip install -r requirements.txt
python train.py --help
```

### 场景分类

```powershell
python train.py scene-prepare `
  --dataset "$env:SCENE_DATASET" `
  --output image_processing/artifacts

python train.py scene-extract `
  --index image_processing/artifacts/scene_index.csv `
  --output image_processing/artifacts/scene_features.csv

python train.py scene-evaluate `
  --features image_processing/artifacts/scene_features.csv `
  --output image_processing/runs/feature_eval_report
```

### 最终八组检测

```powershell
python train.py prepare-comparison `
  --dataset-root "$env:AUGMENTED_DATASET" `
  --output scene_recognition/detector_module/artifacts/comparison_dataset

python train.py detection-matrix --dry-run
python train.py detection-matrix
```

可以只运行一个模型族或指定实验：

```powershell
python train.py detection-matrix --model yolo
python train.py detection-matrix --model resnet
python train.py detection-matrix --only cmp8_yolov8n_aug_pretrained
```

训练输出位于 `scene_recognition/detector_module/runs/`。该目录只在本地存在，不提交 Git。

## Docker 运行

默认镜像安装 CPU 版 PyTorch，适合验证数据准备和程序链路。

```powershell
docker build -t challengecup:cpu .
docker run --rm challengecup:cpu --help
```

挂载本地数据和输出目录：

```powershell
docker run --rm `
  -v "${env:AUGMENTED_DATASET}:/data:ro" `
  -v "${PWD}\local-runs:/workspace/scene_recognition/detector_module/runs" `
  challengecup:cpu `
  prepare-comparison --dataset-root /data
```

GPU 镜像构建示例：

```powershell
docker build `
  --build-arg TORCH_INDEX_URL=https://download.pytorch.org/whl/cu128 `
  -t challengecup:cu128 .

docker run --rm --gpus all `
  -v "${env:AUGMENTED_DATASET}:/data:ro" `
  -v "${PWD}\local-runs:/workspace/scene_recognition/detector_module/runs" `
  challengecup:cu128 `
  detection-matrix
```

GPU 容器需要宿主机安装兼容驱动和 NVIDIA Container Toolkit。实际 CUDA 版本应与显卡驱动、PyTorch 索引保持一致。

## 结果复算

四个标准命名的 YOLO 运行完成后，可以使用与 ResNet18 检测器相同的 AP 实现复算：

```powershell
python train.py yolo-evaluate
```

## 测试

```powershell
python -m unittest discover -v
```

测试不需要提交数据集；涉及真实训练的命令需要团队成员在本地挂载相同版本数据。

## 安全边界

- 不把数据目录复制进仓库或 Docker 镜像。
- 不提交本地生成的 manifests、绝对路径 YAML、权重和运行日志。
- 只提交 `docs/results/` 中经过脱敏的汇总指标。
- 如果需要共享权重，使用访问受控的模型存储，不放在公开 Git 仓库。
