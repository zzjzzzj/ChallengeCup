# 朱润斌的项目学习清单

原则：概念解释、术语和论文摘要交给Chat模式；仓库检查、代码、训练、报错和实验分析再使用Codex。

## 现在：必须会讲清楚

- [ ] **分类、检测、模态**
  - 学会：场景标签、目标标签、IR/SAR分别代表什么。
  - 过关证据：能解释整图目标存在识别、真实框裁剪分类和完整目标检测的区别。
- [ ] **单标签与多标签分类**
  - 学会：四选一使用Softmax；一张图可同时含多个目标时，使用四个独立Sigmoid概率。
  - 过关证据：能解释为什么`soldier+tank`应写成`[1,0,0,1]`，不能强行选一个类别。
- [ ] **YOLO标注与裁剪**
  - 学会：`class_id x_center y_center width height`；比例坐标如何变成像素框。
  - 过关证据：看到一行标注能指出类别、中心和框大小。
- [ ] **训练/验证/测试与数据泄漏**
  - 学会：先按原图划分，再裁剪和增广；同一原图的派生样本不得跨集合。
  - 过关证据：能指出“先增广再随机划分”为什么会虚高。
- [ ] **CNN、Backbone、Head**
  - 学会：卷积网络自动学习特征；ResNet18是骨干，主线最后一层输出四个目标存在分数。
  - 过关证据：能画出“整图→骨干→四个独立概率”。
- [ ] **残差连接**
  - 学会：`输出=F(x)+x`的直觉意义。
  - 过关证据：能解释为什么ResNet比普通深层网络更容易训练。
- [ ] **迁移学习**
  - 学会：ImageNet预训练、冻结、解冻、微调。
  - 过关证据：能说明为什么约3000个裁剪目标不适合盲目从零训练。
- [ ] **分类指标**
  - 学会：Exact Match、Micro/Macro-F1、每类Precision/Recall、阈值。
  - 过关证据：能解释Exact Match 98.20%表示111张测试图中109张的目标集合完全正确；
    并能说明为什么这个数字**不能**证明模型识别了目标（完美场景查表即可得100%）。
- [ ] **检测指标**
  - 学会：IoU、Precision、Recall、mAP@0.5、mAP@0.5:0.95、NMS。
  - 过关证据：能解释为什么99.79% Accuracy不能与81.28% mAP直接比较。

## 下一步：会做实验

- [x] **错误与捷径分析**（2026-07-26 完成，结论：捷径成立）
  - 已学会：平凡基线与像素消融两种检验手段。
  - 已确认：四维标签是场景的确定性函数；抹掉全部目标像素后Exact Match仅由99.10%降到98.20%；
    裁剪分类的不看像素平凡上限为97.67%，ResNet18净增益仅2.12个百分点。
  - 过关证据：能解释"指标高"与"模型学对了"是两回事，
    并能说明为什么必须先证明这个数字不能被平凡方法拿到。
- [ ] **重新定义整图任务**（新增，优先级最高）
  - 学会：什么样的任务设计能让模型无法靠背景蒙对。
  - 过关证据：能提出并实现至少一种不退化的任务（YOLO检测主线／目标计数／跨场景评测）。
- [ ] **模型选择与噪声下限**（新增）
  - 学会：验证集饱和时Macro-F1失效；种子噪声决定了差异的可信阈值。
  - 过关证据：能说明为什么`best.pt`曾被锁死在第1轮，
    以及为什么小于约1.2个百分点（2σ）的组间差异不能声称显著。
- [ ] **数据增强消融**（推迟至上述两项之后）
  - 分别测试none、flip、rotate90、invert、open、close，不同时混入。
  - 过关证据：每种方式有独立运行目录、同一划分、**多种子均值±标准差**和对照表。
  - 注意：`invert`/`open`/`close`是p=1.0的确定性变换，只作用于训练集，
    属于域偏移而非随机增广，须与`flip`/`rotate90`分开表述。
- [ ] **YOLOv8完整检测**
  - 学会训练、验证、误检、漏检和分类别AP。
  - 过关证据：能展示完整原图上的预测框，并解释弱项类别。
- [ ] **IR/SAR分模态实验**
  - 分别报告IR和SAR效果，再比较共享模型、双专家和简单路由。
  - 过关证据：至少有总体/IR/SAR三组可复现指标。
- [ ] **多专家系统**
  - 学会IR专家、SAR专家、门控/路由和结果融合。
  - 过关证据：能说明未配对IR/SAR为何不能直接做像素级融合。
