## 评测协议

| 协议 | Train | Val | Test | 使用范围 |
|---|---:|---:|---:|---|
| A | 525 | 114 | 111 | 场景分类和初始基线 |

协议 C 的 test 场景分布为 air 17、forest 21、sea 17、urban 21，共 76 张图；目标框共 276 个，其中 soldier 63、small_aircraft 70、warship 57、tank 86。

## 本地数据约定

最终原始/增广检测实验使用标准 YOLO 目录：

```text
yolo_augmented/
├─ images/
│  ├─ train/
│  └─ val/
└─ labels/
   ├─ train/
   └─ val/
```

训练目录同时包含原图和增广图，增广文件名包含 `__aug-`。运行以下命令会在本机生成原始组、增广组、val 和 test 清单：

```powershell
python train.py prepare-comparison `
  --dataset-root "D:\datasets\yolo_augmented" `
  --output detector_module/artifacts/comparison_dataset
```

生成目录已被 `.gitignore` 排除，不会上传仓库。
