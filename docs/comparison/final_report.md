# ResNet18 与 YOLOv8n 八组对比实验 · 终版报告

日期：2026-07-27　总耗时：3.5 小时（8 组，单卡 RTX 4060 Laptop）

## 实验设计

三个自变量各两档，2×2×2 = 8 组：

| 自变量 | 档位 A | 档位 B |
|---|---|---|
| 模型 | ResNet18（真值框裁剪四类分类） | YOLOv8n（端到端检测） |
| 训练数据 | 原始集 | 离线增广集 |
| 权重初始化 | ImageNet / COCO 预训练 | 随机初始化（从零） |

**关键控制**：增广组与原始组**共用同一批验证数据**，且原始组就是增广集中不含 `__aug-` 的那部分原图。
两组之间**唯一变量就是有没有离线增广**。

| | 训练规模 | 验证规模 |
|---|---|---|
| ResNet18 | 2388 / 17663 张裁剪 | 569 张裁剪（共用） |
| YOLOv8n | 595 / 4400 张图 | 155 张图（共用） |

超参：ResNet18 40 轮、batch 32、224px、lr 3e-4、seed 42、关闭在线增广；
YOLOv8n 150 轮上限、patience 20、batch 16、640px、seed 42。

## 结论

### 1. 检测任务上，预训练与增广的收益是可加的

| | 无增广 | 有增广 |
|---|---|---|
| 预训练增益 | +3.02 | +3.39 |
| | **增广增益 +2.97** | **增广增益 +2.60** |

交互项仅 ±0.37 个百分点。最差组合（从零+原始）82.37% → 最优组合（预训练+增广）88.36%，
**总增益 +5.99，约等于两项单独增益之和**。两种手段互不替代，应同时使用。

### 2. 分类任务上，两者互为替代——因为指标已经饱和

ResNet18 那边预训练增益从 +2.11 被增广压缩到 +0.70，增广增益在预训练臂上是 0.00。
原因是预训练臂两格都是 **0 个错误**，指标撞到 100% 天花板，测量分辨率只剩 1/569 = 0.176 个百分点。

**这不是"增广无效"，是"量不出来"**。同一份增广数据在未饱和的从零臂上把错误从 12 张降到 4 张（+1.41 点），
在饱和的预训练臂上显示 0.00。两格并排即为自证。

### 3. 全部性能空间集中在 soldier 一个类上

四次干预、两个模型、两种指标，收益去向高度一致：

| 干预 | soldier 收益 | 其余三类收益 |
|---|---|---|
| YOLO 增广（预训练臂） | mAP50 **+11.11** | +0.44 / +0.42 / −0.09 |
| YOLO 增广（从零臂） | mAP50 **+10.18** | +0.18 / +0.05 / −0.01 |
| YOLO 预训练（原始集） | mAP50 **+9.47** | +2.88 / −0.46 / +0.16 |
| ResNet 增广（从零臂） | 召回 **+3.15** | +1.64 / +1.12 / 0.00 |

warship 与 small_aircraft 在全部八组中始终 ≥ 98.9%，任何干预都推不动。
soldier 即便在最优组合下也只有 mAP50 62.66% / 召回 58.27%，**仍是全场最低，仍有一倍提升空间**。

### 4. 难点在"找得到"，不在"认得出"

| 同一个 soldier 类、同一批验证图 | 表现 |
|---|---|
| ResNet18 **给定真值框**做分类 | 召回 **100.0%** |
| YOLOv8n **自己找** | 召回 **40.4%**（最优组合 58.3%） |

差距 60 个百分点。ResNet18 的 100% 是在"难点已被人工去掉"的任务上取得的。

### 5. 增广提升检出、损害框贴合度

| 指标 | 预训练臂 | 从零臂 |
|---|---|---|
| mAP@0.5 | **+2.97** | **+2.60** |
| mAP@0.75 | **−1.24** | **−2.05** |

两臂一致：IoU 阈值低时赚、高时亏。增广让模型找到更多难目标，代价是框画得更松。
这是一个可复现的 trade-off，也是明确的改进抓手。

## 口径与局限（汇报时必须声明）

1. **平凡基线 97.67%**。数据集中目标类别与场景强绑定（small_aircraft 只在 air、warship 只在 sea），
   一个"场景 one-hot + 框宽高"的浅决策树不看任何像素即可达到 97.67% Accuracy。
   ResNet18 的所有数字都必须减去这个平凡上限来解读：从零+原始的 97.89% 仅高出 **0.22 点**，
   即"从头训练基本没学到东西"；增广后的 99.30% 才首次明确站上平凡基线（+1.63）。
   **YOLOv8n 的 mAP 不受此影响**，是本次实验唯一无法靠背景蒙对的指标。

2. **ResNet18 的 test 复用了 val**。增广数据集只提供 train/val 划分，而训练脚本强制要求 test 划分，
   故 test 复用同一批 569 张裁剪。模型选择与最终汇报在同一批数据上进行，**绝对值偏乐观**。
   八组协议完全一致，横向差值仍然可信。YOLOv8n 一侧统一在 val 上评测，不受此影响。

3. **表 1 与表 2 不可横向比较**。ResNet18 的定位由真值框白送，YOLOv8n 必须自己找到目标再分类，
   两者口径不同。要同口径比较需运行 `scene_recognition/detector_module/gt_box_classification.py`。

4. **YOLO 两组的在线增广完全相同**（mosaic 0.6、fliplr 0.5、scale 0.20 等在两组均开启且参数一致）。
   因此"增广 vs 原始"量的是**离线增广在在线增广之上的增量**，会小于离线增广的全部价值。

5. **单种子（seed=42）**。未做多种子重复，差值未附标准差。历史记录显示该任务的种子噪声标准差约 0.61 个百分点，
   故 ResNet18 一侧 +0.70 以下的差值不应作强解读；YOLO 一侧 +2.6 ~ +3.4 的差值明显高于噪声。

## 后续建议

按证据强度排序：

1. **冲小目标检测**。soldier 是唯一的真瓶颈，且远未饱和。可尝试提高输入分辨率、
   增加小目标检测头、或切片推理（SAHI）。这是唯一有大幅提升空间的方向。
2. **放弃在 ResNet18 裁剪分类线上继续调参**。该任务已撞 100% 天花板且贴近平凡基线，
   任何改动都无法测量。
3. **补多种子重复**（seed 43/44），给 YOLO 的 +2.97 / +3.02 附上标准差。
4. **修正框贴合度**。mAP@0.75 在增广后下降，可考虑调整 box loss 权重或减弱 scale 抖动。
