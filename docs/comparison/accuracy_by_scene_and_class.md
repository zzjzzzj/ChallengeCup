# 分场景 / 分目标 识别准确率对照表

八组实验（ResNet18 与 YOLOv8n × 预训练与从零 × 原始集与增广集）的识别准确率，
按**场景**和**目标类别**两个维度分别切片。

> **重要**：这八组实验**没有一组在做场景识别**。ResNet18 分的是 4 类目标，YOLOv8n 检的也是 4 类目标。
> 下表的「分场景」是指**在该场景的图像上，目标识别的准确率**，不是「把场景判断对的准确率」。
> 真正的场景四分类由 `scene_module`（手工特征 + ExtraTrees）负责，是另一条独立技术路线。

# 四、读表要点

1. **air 与 sea 场景在所有八组中都是 99%~100%**，任何干预都推不动 ——
   因为这两个场景各自只含一类目标（small_aircraft / warship），且目标显著、背景干净。

2. **forest 与 urban 是全部难度所在**（65%~79%），因为这两个场景含 soldier。
   全部四组 YOLO 实验中，场景难度排序恒定：sea ≈ air ≫ urban > forest。

3. **预训练与增广的收益全部流向 soldier 与含 soldier 的场景。**
   soldier 的 mAP 提升（+9.47 ~ +11.11）比其他三类高一到两个数量级；
   forest/urban 的提升（+3.94 ~ +8.79）也远高于 air/sea（−0.43 ~ +0.47）。

4. **ResNet18 预训练组四个场景全部 100.00%**，指标完全饱和，无法区分任何设置。
   只有未预训练组还有区分度。

5. **口径提醒**：ResNet18 报的是「给定真值框后的分类准确率」，定位是白送的；
   YOLOv8n 报的是 mAP，需要自己找到目标再分类。两者数值不可直接横向比较。
   另：数据集存在场景—类别强绑定，一个不看像素的浅决策树即可达到 97.67% 准确率，
   ResNet18 的数字须减去这个平凡上限来解读。

训练配置、数据规模与耗时见 `training_details.md`。
