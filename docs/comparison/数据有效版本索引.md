## 最新部署候选

面向华为昇腾 310B，当前新增有效候选为 **YOLOv8n + 960 静态输入 + 增广集 + 预训练**。同一评测器下，相比 YOLOv8n-640 基线：mAP@0.5 从 85.25% 提升到 87.89%，mAP@0.5:0.95 从 40.86% 提升到 44.47%，soldier mAP@0.5 从 51.24% 提升到 60.10%。

- 实验报告：`docs/comparison/昇腾310B-YOLOv8n-960实验报告.md`
- 同口径指标：`docs/comparison/ascend_yolov8n_960_same_evaluator.json`
- 静态 ONNX：`detector_module/runs/ascend_yolov8n_960_aug_pretrained/exports/detector_yolov8n_bs1.onnx`
- 状态：ONNX checker 和 ONNX Runtime 精度验证已通过；OM 转换与 310B FPS 尚需在安装 CANN/ATC 的昇腾设备上完成。

## 四、最终表述建议

可以这样写：

> 本项目最终采用端到端检测口径比较 ResNet18 与 YOLOv8n。ResNet18 已改造为 Faster R-CNN + ResNet18-FPN，和 YOLOv8n 一样输入整张图、输出边界框与类别，并在同一批 76 张独立测试图上用同一套 mAP 评测。结果显示，预训练 ResNet18-FPN 在 mAP@0.5 上略高于 YOLOv8n，最佳为 87.20%；但 YOLOv8n 从零训练更稳定，且在更严格的 mAP@0.5:0.95 上不弱。两类模型共同瓶颈均集中在 soldier 小目标检测。
