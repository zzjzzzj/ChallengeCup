## 1. 技术结论

四组正式实验均已完整跑完六个增量阶段，共生成 24 个阶段模型。**如果目标是最终六类检测精度，当前首选 ER-500**：最终 mAP@0.5 为 **85.24%**，mAP@0.5:0.95 为 **41.97%**，四组中最高；与 ER-200 相比，最终 mAP@0.5 提高 **7.36 个百分点**，平均遗忘由 **12.21%** 降至 **5.76%**，仅增加约 **4.44 分钟**训练时间。

**如果优先考虑旧类稳定性，DER-500 最好**：其 mAP@0.5 平均遗忘仅 **2.56%**，BWT 为 **-0.20%**，最接近零。但其最终 mAP@0.5 为 **81.08%**，比 ER-500 低 **4.16 个百分点**；主要损失来自最后新增的装甲车辆，DER-500 在该类上的 mAP@0.5 为 **76.82%**，而 ER-500 为 **98.68%**。这说明当前 DER 配置明显偏向稳定性，抑制了新类可塑性。

当前系统**已经输出“每个增量阶段、每个已见类别”的 Precision、Recall、mAP@0.5 和 mAP@0.5:0.95**。本报告用 mAP@0.5 作为“识别率”的主要比较口径，并完整列出四组实验的阶段—类别矩阵。需要特别区分：

- “每次训练”若指每个增量阶段 T1～T6：已经完整输出；
- “每次训练”若指每个 epoch：当前 `results.csv` 仅保存该 epoch 的总体 Precision、Recall、mAP，不保存逐类别 epoch 曲线。

综合判断：当前 Class-IL 流程已能用于正式的单次基线实验和方法比较，但在对外下最终结论前，仍应补充多随机种子重复、罕见类别扩充以及 DER 超参数搜索。

## 2. 实验目标与协议

### 2.1 类别到达顺序

六个类别严格按以下顺序逐类训练：

| 阶段 | 新增类别 | 阶段结束时可识别的类别 |
|---|---|---|
| T1 | `soldier`（士兵） | 士兵 |
| T2 | `small_aircraft`（小型飞行器） | 士兵、小型飞行器 |
| T3 | `warship`（军舰） | 士兵、小型飞行器、军舰 |
| T4 | `tank`（坦克） | 士兵、小型飞行器、军舰、坦克 |
| T5 | `patrol_boat`（巡逻艇） | 前五类 |
| T6 | `armored_vehicle`（装甲车辆） | 全部六类 |

训练采用单一、逐步扩展的检测头。阶段 Tt 的当前训练数据只提供第 t 个新类的普通训练监督，同时混入固定容量的旧类回放样本；上一阶段的最佳 checkpoint 作为下一阶段初始模型。验证和测试只覆盖截至当前阶段已经出现的类别，未来类别不会进入当前阶段的监督或评测。

### 2.2 ER 与 DER

**ER（Experience Replay）**将当前新类样本与旧类缓冲样本混合，并使用标准 YOLO 检测损失训练：

```text
L_ER = L_box + L_cls + L_dfl
```

**DER（Dark Experience Replay）**在与 ER 相同的监督回放基础上，冻结上一阶段模型作为教师，只在 replay 样本上匹配上一阶段的分类与边框原始响应：

```text
L_DER = L_box + L_cls + L_dfl
      + lambda_der * (lambda_cls * L_dark_cls + lambda_box * L_dark_box)
```

本次正式实验采用：

```text
lambda_der = 1.0
lambda_cls = 1.0
lambda_box = 0.25
der_min_confidence = 0.0
```

教师响应在线计算，不写入磁盘 logit 缓存；新增类别通道不参与旧教师响应匹配。当前实现属于目标检测版在线 DER，而不是在全部新类图像上施加蒸馏的普通 LwF。

### 2.3 回放缓冲池

正式比较固定为四组：

| 方法 | 缓冲池容量 |
|---|---:|
| ER | 200 张图像 |
| ER | 500 张图像 |
| DER | 200 张图像 |
| DER | 500 张图像 |

缓冲池按已学习类别进行轮转和平衡抽样，并优先覆盖不同原始帧，避免少量原图的多个增广版本占满缓冲池。训练阶段只使用上一阶段结束时形成的缓冲池。

## 5. 指标定义

设 `R[t,i]` 表示完成阶段 t 后，模型在已见类别 i 上的测试指标。本报告同时对 mAP@0.5 和 mAP@0.5:0.95 计算以下持续学习指标：

- **Final mAP**：T6 后全部六类的算术平均；
- **AIA（Average Incremental Accuracy）**：六个阶段“当前全部已见类别平均指标”的平均；
- **Average Forgetting**：对前五个类别，计算历史最佳值减去 T6 最终值，再取平均；越小越好；
- **BWT（Backward Transfer）**：对前五个类别，计算 T6 最终值减去该类别首次学习后的值，再取平均；越接近 0 或为正越好。

公式为：

```text
AIA = mean_t(mean_{i<=t}(R[t,i]))

Forgetting = mean_{i<T}(max_{t>=i}(R[t,i]) - R[T,i])

BWT = mean_{i<T}(R[T,i] - R[i,i])
```

“识别率”不是目标检测中的单一标准术语。为避免阈值依赖，本报告以 **mAP@0.5** 作为主要识别能力口径，同时保留更严格的 mAP@0.5:0.95、Precision 和 Recall。Precision/Recall 取决于评测置信度与匹配策略，不宜脱离 mAP 单独解释。

## 6. 四组实验总体结果

| 方法 | Final mAP50 | Final mAP50-95 | AIA50 | 遗忘50 | BWT50 | AIA95 | 遗忘95 | BWT95 | 耗时 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| ER-200 | 77.88% | 37.68% | 73.98% | 12.21% | -9.90% | 34.49% | 6.31% | -4.65% | 69.60 min |
| **ER-500** | **85.24%** | **41.97%** | **76.80%** | 5.76% | -2.69% | **36.06%** | 3.69% | -0.74% | 74.04 min |
| DER-200 | 75.80% | 36.73% | 70.38% | 5.55% | -3.02% | 32.90% | 2.95% | -1.10% | 69.89 min |

结论可以分成两个方向：

1. **最终精度与训练性价比：ER-500 最优。**它取得最高最终 mAP，并且比 ER-200 只多耗时约 6.4%。
2. **抗遗忘：DER-500 最优。**它的遗忘和 BWT 最好，但比 ER-500 多耗时约 25.2%，同时牺牲了新类学习能力。

四组实验合计耗时 **18,372.595 秒，即 306.21 分钟（约 5.10 小时）**。

## 15. 限制与不确定性

1. **只有一个随机种子。**当前结果不能给出均值、标准差或置信区间，方法排序可能受初始化和采样波动影响。
2. **少数类独立样本较少。**巡逻艇和装甲车辆的 test 各只有 7 个原图来源组，个别场景会显著影响指标。
3. **类别顺序固定。**这里只证明 `soldier → small_aircraft → warship → tank → patrol_boat → armored_vehicle` 顺序下的表现，不能直接外推到其他到达顺序。
4. **本地 test 不是竞赛隐藏测试。**它适合方法内部比较，但不能代表最终竞赛排名。
5. **DER 只测试了一组权重。**当前结论是“该 DER 配置”的结果，不是 DER 方法的理论上限。
6. **没有联合训练上界。**缺少同一数据、同一基础模型和相同训练预算下的六类联合训练结果，尚不能量化持续学习相对离线上界的差距。
7. **当前逐 epoch 日志不是逐类别日志。**本报告的完整矩阵粒度是增量阶段，而非 epoch。

1. **将 ER-500 固定为主基线。**后续所有新方法都同时报告最终 mAP、AIA、遗忘、BWT、耗时和分类别矩阵，避免只看单一最终平均值。

主要原因是：**原论文公式面向图像分类，不能原样套到 YOLO 目标检测上**。但当前实现中也包含了一些工程选择，并非全部都是“必须修改”。

可以分成两类来看。

### 必须适配的部分

1. **YOLO 不只有分类 logits**

原始 DER 每张图只有一个固定长度的分类向量：

```
z = [class_1, class_2, ..., class_n]
```

而 YOLO 在多个尺度、成千上万个位置输出：

```
分类响应 + 边框分布响应
```

如果只保持分类响应，模型可能仍记得“这是什么”，却忘记“目标在哪里”。因此项目加入了：

```
L_dark_cls + 0.25 × L_dark_box
```

分类蒸馏保存类别知识，边框蒸馏保存定位能力。

1. **检测输出绝大部分是背景**

分类模型每张图只有一组 logits；检测模型可能有数千个候选位置，其中大部分没有目标。如果直接对所有位置做无权重 MSE，损失很容易被背景响应淹没。

所以当前实现使用教师置信度加权：

```
weight = teacher_confidence
```

让真正可能包含旧目标的位置贡献更大。相关实现位于 [dark_experience_replay.py (line 178)](I:\\项目\\ChallengeCup\\scene_recognition\\detector_module\\dark_experience_replay.py:178)。

1. **类别数量逐阶段增加**

原始分类实验通常使用固定输出维度；本项目检测头从 1 类扩展到 6 类：

```
T1: 1 class
T2: 2 classes
...
T6: 6 classes
```

上一阶段教师没有新类别通道，所以只能匹配已有旧类通道，不能直接对教师和学生的完整输出做 MSE。

### 属于工程选择、并非必须的部分

最大的改动是：**没有保存样本进入缓冲池时的历史 logits，而是使用上一阶段冻结模型在线生成响应。**

原论文方式：

```
buffer = image + historical_logits
```

当前项目方式：

```
buffer = image + label
dark_target = frozen_previous_stage_model(image)
```

这样选择主要有几个现实原因：

- YOLO 的多尺度稠密响应远大于普通分类 logits，缓存 200～500 张图的完整分类和边框响应会占用较多空间；
- 检测响应与输入分辨率、增广方式、特征层尺寸紧密绑定，缓存后必须保证重放时的几何变换完全一致；
- 在线教师可以对当前增广后的图像生成尺寸匹配的响应；
- 项目本来就是有明确 T1～T6 边界的阶段式 Class-IL，天然可以使用上一阶段 checkpoint；
- 不需要设计额外的 logit 缓存格式和版本兼容机制。

代价是训练更慢——这也是 DER-500 比 ER-500 多耗时约 18.65 分钟的主要原因之一。

### 为什么还保留真实标签回放

原始 DER 主要使用历史 logits；DER++ 才增加缓冲样本的真实标签监督。

当前实现以 ER 为基础：

```
当前新类监督
+ 旧类真实标签回放
+ 旧类暗响应匹配
```

这是因为目标检测不仅要分类，还要学习边框回归。只依靠教师响应可能把教师原有的漏检和定位误差一并保留下来。加入真实标签可以继续纠正旧类检测错误。

所以当前方法实际上更接近：

> DER++ 的监督回放结构 + 上一阶段在线教师 + 检测框响应蒸馏。

### 这会不会影响实验结论？

会。当前结果只能称为“本项目检测版 DER”的结果，不能直接代表原论文 DER。

特别是当前 DER-500：

- 遗忘率比 ER-500 更低；
- 但装甲车辆 mAP50 从 ER-500 的 98.68% 降到 76.82%。

这可能说明“监督回放 + 分类蒸馏 + 边框蒸馏”的总约束偏强，学生过度保持旧模型，降低了学习新类的能力。不过这只是基于结果的合理推断，还需要消融实验确认。

如果用于正式论文，最严谨的做法是增加三个方法：

```
ER
DER-Cached：尽量复现原论文，缓存历史响应
DER-Online：当前在线教师检测版
DER++-Online：在线教师 + 真实标签回放
```

再分别消融：

```
分类蒸馏
分类 + 边框蒸馏
置信度加权
在线教师 / 缓存响应
```

因此，不使用原公式的核心理由是检测任务需要适配；但“在线上一阶段教师”和“监督回放”属于工程设计选择。当前实现具有合理性，只是方法名称更准确地应该写成 **Online Teacher DER-style Detection Replay**，而不是声称严格复现原始 DER。

代码中的核心关系是：

> **ER = 固定容量、类别均衡的真实标签经验回放；DER = 完整 ER + 仅对回放图像施加的上一阶段教师响应约束。**

```
阶段数据
  ├─ 当前新类图像
  └─ 旧类缓冲池图像
          │
          ▼
     标准 YOLO 监督损失
          │
          ├─ ER：直接更新学生模型
          │
          └─ DER：再调用冻结教师
                    ├─ 分类响应 MSE
                    └─ 边框响应 MSE
                         │
                         ▼
                    更新学生模型
```

## 1. 两种方法共用的回放池

回放池由 [prepare_class_incremental_dataset.py (line 227)](I:\\项目\\ChallengeCup\\scene_recognition\\detector_module\\prepare_class_incremental_dataset.py:227) 提前生成。

选择过程是：

1. 找出已经学习过的旧类别；
2. 按类别轮转选择样本，尽量保证类别均衡；
3. 按原始图像来源 `source_key` 分组；
4. 优先选择不同原图；
5. 原图覆盖后才继续选择同一原图的增广版本；
6. 同一张图片不会重复进入缓冲池；
7. 总数不超过 200 或 500。

这不是论文中的在线 Reservoir Sampling，而是**离线、确定性、类别均衡回放池**。

每阶段的训练视图由两部分组成：

```
current samples：当前新类别样本
replay samples：旧类别缓冲池样本
```

代码会生成：

```
train.txt
replay.txt
data_buffer_200.yaml
data_buffer_500.yaml
buffer_before_*.json
buffer_after_*.json
```

其中：

- `train.txt` 包含当前数据和回放数据；
- `replay.txt` 只记录哪些图像来自缓冲池；
- ER 只需要 `train.txt`；
- DER 额外使用 `replay.txt` 判断哪些图像需要教师蒸馏。

训练视图生成位于 [prepare_class_incremental_dataset.py (line 289)](I:\\项目\\ChallengeCup\\scene_recognition\\detector_module\\prepare_class_incremental_dataset.py:289)。

一个重要细节是：每个样本的标签只保留其在当前视图中承担的那个类别。例如当前阶段是坦克，则普通当前样本只保留坦克框；回放槽属于士兵，则只保留士兵框。

## 2. ER 的代码实现

ER 没有自定义模型或自定义损失函数，而是通过**混合训练数据**实现。

训练阶段执行：

```
model = YOLO(previous_checkpoint)
model.train(data=stage_data_yaml, ...)
```

关键分支位于 [train_class_incremental_yolo.py (line 372)](I:\\项目\\ChallengeCup\\scene_recognition\\detector_module\\train_class_incremental_yolo.py:372)。

`stage_data_yaml` 的训练清单已经包含：

```
当前新类数据 + 旧类回放数据
```

因此标准 YOLO 损失会同时作用于两种样本：

```
L_ER = L_box + L_cls + L_dfl
```

这里没有单独的 `replay_weight`。当前样本和回放样本的相对影响主要由：

- 两类样本数量；
- Ultralytics 的数据打乱和 batch 组成；
- YOLO 自身损失归一化方式；

共同决定。

ER 的阶段流程是：

```
加载上一阶段 best.pt
        ↓
根据 data_buffer_*.yaml 扩展到当前已见类别
        ↓
当前新类 + 旧类回放混合训练
        ↓
保存本阶段 best.pt
        ↓
在累计 val/test 上评测
        ↓
本阶段 best.pt 成为下一阶段初始模型
```

T1 没有旧类，因此没有回放；从 T2 开始才加入缓冲池。

## 3. DER 的代码实现

DER 使用与 ER **完全相同的数据和真实标签监督**，然后额外增加暗响应损失。

当：

```
method == der
并且 stage > 1
```

训练器会把普通学生模型包装为 `DarkReplayModel`。入口位于 [train_class_incremental_yolo.py (line 165)](I:\\项目\\ChallengeCup\\scene_recognition\\detector_module\\train_class_incremental_yolo.py:165)，主体位于 [dark_experience_replay.py (line 212)](I:\\项目\\ChallengeCup\\scene_recognition\\detector_module\\dark_experience_replay.py:212)。

### 教师和学生

每个 DER 阶段包含：

```
教师模型：上一阶段 best.pt，冻结，不更新
学生模型：由上一阶段 best.pt 初始化，扩展新类别后继续训练
```

优化器只接收学生模型参数，教师不会获得梯度或优化器状态。

### 如何判断回放样本

一个 batch 进入模型后，代码读取：

```
batch["im_file"]
```

然后与 `replay.txt` 中的本地路径进行匹配，生成布尔掩码：

```
mask = replay_batch_mask(files, replay_paths)
```

对应代码位于 [dark_experience_replay.py (line 269)](I:\\项目\\ChallengeCup\\scene_recognition\\detector_module\\dark_experience_replay.py:269)。

因此：

- 当前新类图像：只计算普通 YOLO 损失；
- replay 图像：计算普通 YOLO 损失和 DER 暗响应损失；
- batch 没有 replay 图像：DER 损失为 0。

### 暗响应如何计算

学生先对完整 batch 前向计算，获得普通 YOLO 损失：

```
L_YOLO = L_box + L_cls + L_dfl
```

教师只对 replay 子集进行前向计算：

```
with torch.no_grad():
    teacher_predictions = teacher_model(replay_images)
```

之后分别匹配分类响应和边框响应。

分类响应：

```
L_dark_cls =
    weighted_mean((student_old_cls - teacher_old_cls)²)
```

边框响应：

```
L_dark_box =
    weighted_mean((student_box - teacher_box)²)
```

只匹配学生的旧类别通道：

```
student[:, :old_class_count]
```

新增类别通道不受教师约束，否则教师没有新类知识，却会阻止学生学习新类。

具体实现位于 [dark_experience_replay.py (line 130)](I:\\项目\\ChallengeCup\\scene_recognition\\detector_module\\dark_experience_replay.py:130)。

### 教师置信度加权

每个检测位置的权重为：

```
confidence = max(sigmoid(teacher_old_class_logits))
weight = confidence × (confidence >= min_confidence)
```

目的是降低大量背景位置对 MSE 的支配。

当前：

```
min_confidence = 0.0
```

表示所有位置都可参与，但仍按照教师置信度连续加权；低置信度背景位置的影响较小。

### 最终 DER 损失

代码中的实际形式是：

```
L_response =
      der_cls_weight × L_dark_cls
    + der_box_weight × L_dark_box

L_DER = L_YOLO + der_weight × L_response
```

当前参数代入后：

```
L_DER = L_YOLO
      + 1.0 × (
            1.0 × L_dark_cls
          + 0.25 × L_dark_box
        )
```

## 4. ER 与 DER 的直接差别

| 项目             | ER       | DER            |
| ---------------- | -------- | -------------- |
| 当前新类真实标签 | 使用     | 使用           |
| 旧类回放真实标签 | 使用     | 使用           |
| 上一阶段冻结教师 | 不使用   | 使用           |
| 分类响应匹配     | 无       | 有             |
| 边框响应匹配     | 无       | 有             |
| 蒸馏范围         | 无       | 仅 replay 图像 |
| 历史 logits 缓存 | 无       | 无，在线计算   |
| T1 行为          | 普通训练 | 与 ER 相同     |
| 训练开销         | 较低     | 较高           |

所以当前代码可以概括为：

```
ER  = supervised replay
DER = supervised replay
    + online previous-stage teacher
    + confidence-weighted class distillation
    + confidence-weighted box distillation
```

它不是原论文的缓存-logits DER，而是一个面向 YOLO 的、以 ER 为底座的在线教师检测版 DER。
