## 二、数据集与测试协议

### 2.1 数据规模

| 数据 | 图像规模 | 目标框规模 |
|---|---:|---:|
| 原始数据全集 | 750 图 | 2957 框 |
| 原始基线训练划分 | 525 train + 114 val + 111 test | 2025 + 459 + 473 框 |
| 早期增广对比原始训练集 | 595 train + 155 val | 2388 + 569 框 |
| 增广训练集 | 4400 train + 155 张未增广留出图 | 17663 + 569 框 |
| 最终干净对比 | 595 或 4400 train + 79 val + 76 test | 155 张留出图被拆成 79/76 |

### 2.2 三套正式测试协议

| 协议 | 测试/留出规模 | 使用记录 | 是否独立测试 |
|---|---:|---|---|
| A：原始基线 | 111 张图；裁剪任务为其中 473 个框 | 场景分类、ResNet18 原始裁剪基线、ResNet18 两个整图基线、旧 YOLO 参考基线 | 是 |
| B：早期增广对比 | 155 张图；裁剪任务为其中 569 个框 | `cmp_resnet18_*`、`cmp_yolov8n_*`、YOLO 真实框匹配复算 | 否；同一留出集参与选模和汇报 |
| C：最终干净对比 | 76 张图、276 个框 | `cmp_whole_*`、`cmp8_resnet18det_*`、`cmp8_yolov8n_*`、YOLO 同评测器复算 | 是；另有 79 张 val 选模 |

逐文件名核对结果：

- 场景分类 111 张与协议 A 检测清单 111 张完全一致。
- 协议 C 的 76 张全部来自协议 B 的 155 张留出集。
- 协议 A 的 111 张与协议 B 的 155 张只重合 32 张。
- 协议 A 的 111 张与协议 C 的 76 张只重合 15 张。
- `cmp_whole_noaug/aug` 的 76 张 test 与协议 C 的 `clean_test.txt` 完全一致。

结论：**所有测试集并不相同。只有同一协议内部的实验使用相同测试来源。** 即使源图相同，裁剪分类按目标框计样本、检测按整图计样本，指标仍不能直接比较。

## 十、最终可直接回答的问题

### 测试集都是一样的吗？

**不是。** 项目先后使用了 111 张、155 张和 76 张三套协议。

- 协议 A 内部相同：场景分类、原始 ResNet18 基线和旧 YOLO 参考基线来自同一套 525/114/111 划分。
- 协议 B 内部相同：四个裁剪 ResNet18 与四个早期 YOLO 模型都来自同一批 155 张留出图，但裁剪模型按 569 个框评估，YOLO 按 155 张整图评估；而且这批数据同时用于选模和汇报。
- 协议 C 内部相同：最终 ResNet18 整图存在判断、ResNet18 端到端检测和 YOLOv8n 干净八组都使用同一批 76 张独立 test。
- 跨协议的分数不能直接比较。最终模型横向比较应只使用协议 C 和同一评测器复算结果。
