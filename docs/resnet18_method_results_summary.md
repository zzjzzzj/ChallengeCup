# ResNet18整图目标识别方法与结果

## 1. 实验目标

输入一张完整遥感图，直接判断图中是否存在以下四类目标：

- `soldier`
- `small_aircraft`
- `warship`
- `tank`

一张图可能同时包含多个类别，因此本实验采用**多标签分类**，不是四选一分类。

## 2. 方法

```text
完整遥感图
    ↓
补边为正方形、缩放至224×224、ImageNet归一化
    ↓
ImageNet预训练ResNet18
    ↓
输出4个独立概率
    ↓
分别判断4类目标是否存在
```

### 2.1 标签处理

从YOLO标注中读取目标类别，忽略目标框位置，只保留每个类别是否出现。

例如，一张图同时包含士兵和坦克，其整图标签为：

```text
[soldier, small_aircraft, warship, tank]
[   1,           0,          0,     1]
```

### 2.2 训练设置

| 项目 | 设置 |
|---|---|
| 模型 | ResNet18 |
| 预训练 | ImageNet |
| 输入尺寸 | 224×224 |
| 训练轮数 | 12 |
| Batch Size | 32 |
| 优化器 | AdamW |
| 损失函数 | BCEWithLogitsLoss |
| 类别平衡 | 使用正样本权重 |
| 数据增强 | 无增强，作为基准组 |
| 模型选择 | 验证集Macro-F1最高 |
| 分类阈值 | 在验证集上分别确定 |
| 随机种子 | 42 |

数据先按原图划分，再进行训练。程序会检查同一原图是否跨训练集、验证集和测试集，防止数据泄漏。

## 3. 数据情况

测试集目标分布：

| 目标类别 | 正样本图片数 |
|---|---:|
| soldier | 60 |
| small_aircraft | 27 |
| warship | 24 |
| tank | 60 |

测试集中有60张图片同时包含`soldier`和`tank`。
但需要注意：这60张恰好就是全部的urban与forest图片，
且**每一张**urban/forest图都同时含这两类，标签没有任何变化，
因此这不构成"真正的多标签样本"证据（详见第5节）。

## 4. 最终结果

> **2026-07-26 更正。** 此前本节公布的 Exact Match 90.99% / Macro-F1 92.37%
> 来自**第1轮欠训练权重**：验证集Macro-F1第1轮即饱和到1.0，而模型选择使用严格大于，
> `best.pt` 被永久锁定在第1轮。修正选择规则后选中第8轮。
> 详见 [`诊断报告-场景捷径与模型选择缺陷.md`](诊断报告-场景捷径与模型选择缺陷.md)。

### 4.1 总体结果

产物：`scene_recognition/target_classifier_module/runs/resnet18_whole_image_fixed_selection_none/`

| 指标 | 修正前（第1轮） | 修正后（第8轮） |
|---|---:|---:|
| Exact Match | 90.99% | **98.20%** |
| Micro-F1 | 94.77% | **98.54%** |
| Macro-F1 | 92.37% | **98.30%** |

3个随机种子的测试Macro-F1为 **98.15%±0.61**。
测试集仅111张，1张图 = 0.90个百分点。

## 5. 错误分析与捷径判决

- 修正后IR仍是相对弱项（97.50% vs SAR 100.00%），`warship`是最弱类别（F1 95.65%）。
- **类别与场景的绑定已由"可能"确认为"成立"。** 四维存在标签是场景的确定性函数：
  air恒为`[0,1,0,0]`、sea恒为`[0,0,1,0]`、urban与forest恒为`[1,0,0,1]`，
  750张图零例外，全数据集只出现3种存在向量（理论有16种）。
  **完美场景分类器的Exact Match就是100.00%，高于本模型的98.20%。**
- 测试集像素消融判决：

  | 条件 | Exact Match |
  |---|---:|
  | 原图 | 99.10% |
  | **抹掉全部真实框内像素（目标消失、背景保留）** | **98.20%** |
  | 只保留目标、抹掉背景 | 34.23% |
  | 参考：恒定预测`[1,0,0,1]` | 54.05% |

  抹掉图中每一个目标像素后只多错1张图；只留目标反而低于恒定预测。
  **结论：模型依赖背景场景，不依赖目标本身。**
- 验证集12个轮次的Macro-F1全部为1.0，已完全失去区分能力，
  任何基于验证集Macro-F1的模型选择都是随机的。

复现：

```powershell
python -m scene_recognition.target_classifier_module.diagnose_shortcut `
  --manifest-dir scene_recognition/detector_module/artifacts/detection_dataset/manifests `
  --checkpoint scene_recognition/target_classifier_module/runs/resnet18_whole_image_fixed_selection_none/best.pt `
  --output scene_recognition/target_classifier_module/runs/shortcut_diagnosis
```

## 6. 对照实验

| 方法 | 任务 | 结果 | 不看目标像素的平凡基线 |
|---|---|---|---|
| ResNet18整图多标签 | 判断整图中有哪些目标 | Exact Match 98.20%，Macro-F1 98.30% | 完美场景查表 **100.00%** |
| ResNet18真实框裁剪分类 | 已知位置后判断单个目标类别 | Accuracy 99.79%，Macro-F1 99.78% | 场景+框尺寸决策树 **97.67%** |
| YOLOv8n目标检测 | 同时定位和分类目标 | mAP@0.5 81.28%，mAP@0.5:0.95 37.17% | 无平凡解 |

三种方法解决的任务不同，Exact Match、分类Accuracy和检测mAP不能直接比较。
更关键的是：前两行的结果都**没有超过各自的平凡基线**，
只有YOLOv8的mAP无法靠场景背景蒙对。

## 7. 结论

修正模型选择规则后，ResNet18整图多标签模型的测试Exact Match为98.20%、Macro-F1为98.30%
（3种子 98.15%±0.61）。工程链路（数据划分、防泄漏、训练、评价、导出）是可复现的。

但**这个数字不能作为"ResNet18已经能够识别目标"的证据**：

1. 该任务的四维存在标签是场景的确定性函数，完美场景分类器即可得到100% Exact Match；
2. 像素消融证明，抹掉图中全部目标像素后Exact Match仅从99.10%降到98.20%，
   模型读的是背景而不是目标。

因此该方法应表述为"整图场景级存在性判断"，它既不输出目标位置和数量，
也未证明模型识别了目标本身。要汇报目标识别能力，
应以YOLOv8检测的Precision/Recall/mAP为准，或先按诊断报告第9节重新定义任务。
